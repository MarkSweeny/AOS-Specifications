3. Shared logical types and envelope

R means exactly one required value; C means required under the stated condition; O optional. ref is an exact organisation, identity and revision triple; refs is a collection of such triples. Unqualified collection cardinality is R 0..n; where at least one member is necessary the definition says R 1..n. A required collection can be empty only with an explicit reason permitted by the named profile. No absent bound means unlimited power.

key is a nonempty controlled semantic identifier; text is explanatory content governed by access rules, not executable instructions. time is a tagged calendar date or timestamp: preserve precision and calendar/time basis; timestamps name zone/offset and known clock uncertainty. quantity contains value, unit and approved range/profile; quantities with incompatible units are invalid without a reviewed conversion. scope contains typed subjects, fields/operations, purpose and organisation boundary plus the exact profile. value is tagged known, unknown, unavailable, withheld or not_applicable; non-known tags require reason and governing profile. Withheld values reference an authorised disclosure rule. Mandatory unknown values cannot satisfy a dependent favourable check.

Every supporting shape in §5 uses Core Records §2.1 shared header, extended by these exchange fields; existing REC headers consume the same fields through the Core v0.3 amendment:

Conflicting contents under the same identity/revision are rejected as conflict, with permitted evidence preserved; identical repeats may be acknowledged against the original but do not refresh permissions or establish a new effect. Corrections are new revisions linked to the original, under the approved retention/deletion policy. Receiving systems validate types/cardinalities/vocabularies, organisation, role, references, version, purpose and restrictions before reliance. Secret values and unnecessary private content never enter the header. A permitted projection can replace protected content only if the intended consumer can still establish the required meaning; otherwise the dependent conclusion remains unresolved.
